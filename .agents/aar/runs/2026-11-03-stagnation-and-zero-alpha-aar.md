## Исправления

1. **Динамический лимит слотов (`trader.py`):** при `active_category_filter != 'ALL'` лимит для активной категории расширяется с 3 до 6 (до 75% всех доступных слотов), устраняя заморозку 76% кэша.
2. **Ликвидация фиктивного Edge (`oracles.py`):** `MatureMarketConsensusOracle` возвращен к строгому порогу зрелости $P \ge 0.90$. В диапазоне $0.76–0.89$ запрещено генерировать сделки простым сложением $P_{mkt} + 0.035$. В этом диапазоне вход разрешен только при наличии независимого структурного перекоса (форы -3.5+, асимметрия стакана OBI $\ge 0.40$, базовые вероятности).
3. **Починка воронки песочницы (`trader.py`):** для теневых кандидатов сортировка изменена на отбор рынков с ценой `0.20 <= p <= 0.80`, устраняя конфликт с фильтром исполнения `0.15 <= p_est <= 0.85`.
4. **Тесты в `tests_risk.py`:**
   - `test_single_category_slot_expansion`: подтверждает, что моно-категория может использовать до 6 слотов.
   - `test_shadow_candidate_funnel_not_starved`: подтверждает, что теневые кандидаты не отсекаются сортировкой.
   - `test_mature_consensus_oracle_strict_threshold`: подтверждает отсечение ставок без альфы при $P < 0.90$.

## Чем доказано, что ловится

- Падающий тест на старом коде: `cat_cap` блокировал 4-ю позицию в Sports.
- Проходящий тест на новом коде: открывается 6 позиций, капитал утилизируется.
- Проверка воронки песочницы: отбираются рынки с ценой $0.20–0.80$, песочница начинает открывать сделки.
